# The product: "hello-world" (version 1.43)

Your employer installed this on every Windows work PC. It's free to you; IT deployed it. It lives in the Start menu.

What it does, in plain terms:
- Each day it shows a greeting ("Hello, world!"), the date, one short "thought for today" and one small "try this today" tip. Everyone in the company sees the same thought and tip on the same day.
- You can type ONE plan for the day (or a few things separated by ";"). Next day it asks "Did you do it?" — Done / Not yet / Skip.
- If you write a date or weekday in the plan ("by Friday", "30/10") it becomes a due date.
- It opens as a normal window with buttons by default. There is also a text-only screen (shown below) that some people switch to.
- Optional: a Windows notification at sign-in asking about yesterday's plan, with Done / Not yet buttons right in the notification.
- Menu has 12 options: show what's saved, sign-in reminder on/off, days-in-a-row message, delete everything, help, set/change plan, forget a finished plan, hide thought and tip, switch window/text screen, language (13 languages), mark plan done, more settings (due date, save plans to a spreadsheet file, etc).
- It saves one small file on your PC. Nothing is sent anywhere. No accounts, no scores, no network. IT could technically read the file like any work file.
- "Days in a row" message appears on your 3rd, 7th, 14th visit in a row.
